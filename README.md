# ホンネカード 🃏

チームで「ぶっちゃけトーク」をするためのトークカードアプリです。

10枚の裏向きカードから1枚をみんなで選び、めくるとお題が出てきます。
そのお題についてチームで本音で語り合い、話し終わったらカードを除外して次へ。
全部めくり終えると紙吹雪でお祝いします 🎉

ファシリテーターがPCを操作し、大画面（プロジェクターや大型モニター）に映して全員で使うことを想定しています。

## 使い方

公開ページをブラウザで開くだけで、すぐに使えます。

1. 「カードを配る」ボタンを押す
2. デッキがシャッフルされ、10枚のカードが配られる
3. 気になるカードをクリックすると、カードがめくれてお題が表示される
4. お題についてチームで話す
5. 「話し終わり！」を押すとカードが消え、残りから次を選ぶ
6. 全部話し終わると完了画面に

ネット環境がなくても、`index.html` をPCにダウンロードしてダブルクリックすれば同じように動きます。

## 特徴

- **ブラウザだけで完結**：サーバー不要。`index.html` 1ファイルだけで全機能が動きます
- **オフラインでも動く**：アニメーションに使うライブラリ（GSAP・canvas-confetti）はファイル内に埋め込み済みなので、ネットが不安定な会場でも安心
- **なめらかな演出**：カードを配る動き、シャッフル、フリップ、紙吹雪まですべてアニメーション付き
- **大画面向け**：画面の高さに合わせてカードが大きく表示されます

## お題の編集

`index.html` の冒頭にある `TOPICS` という部分を書き換えるだけで、お題を自由に変更できます。

```js
const TOPICS = [
  "ここに質問を書く",
  "2つ目の質問",
  // ... 10個まで
];
```

## 動作環境

- Google Chrome 最新版を推奨
- 大画面PC表示向け（スマホ表示は未対応）

## 技術メモ

- シングルHTMLファイル（HTML + CSS + Vanilla JavaScript）
- アニメーション：[GSAP](https://gsap.com/) 3.12.5
- 紙吹雪：[canvas-confetti](https://github.com/catdad/canvas-confetti) 1.9.3
